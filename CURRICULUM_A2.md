# TurkoLinguo — A2 curriculum outline (draft v0.1)

Continues the A1 course ([CURRICULUM.md](CURRICULUM.md)): same principles (one rule per lesson, rule card → examples → practice with explained feedback → spaced review), same notation (A I D C K, (y) (n) (s) buffers), same content format ([docs/CONTENT_FORMAT.md](docs/CONTENT_FORMAT.md)).

**Talk tasks:** every A2 lesson's Practise ends with a talk task, and every checkpoint has one (a `talk` block, see [docs/TALK_TASKS.md](docs/TALK_TASKS.md)). Its §6 has a draft task for each of L36–L64; write it with the lesson, from the start.

**Numbering continues:** lessons **L36–L64**, units **U8–U13**, checkpoints **C8–C13**, theme packs **T22–T31**.

**Size:** 29 lessons + 6 checkpoints ≈ 64 core sessions. Vocabulary target: about **+650 words** (A1 ≈ 490 in the lexicon so far → ≈ 1,150 by the end of A2).

**What A2 adds, in one line per unit:**

| Unit | Theme | Grammar |
|---|---|---|
| U8 | Habits & offers | aorist, can / can't, must, let's |
| U9 | Finding your way | where things are (*üstünde*), *-ki*, postpositions, ordinals |
| U10 | Telling stories | was …-ing, apparently (*-mIş*), while / when / after / before |
| U11 | If and how | if (*-sA*), by doing (*-ArAk*), and then (*-Ip*), *-mAyI* as an object |
| U12 | People & things | relative clauses *-(y)An*, *kendi*, *hiç / kimse*, *gibi / kadar* comparisons |
| U13 | Opinions & plans | *-DIK* relative clauses, purpose *-mAk için*, *bence*, connectors |

## 1. Lesson map

Format as in A1: **grammar point** · rule summary · examples · pitfalls · vocabulary theme.

### Unit 8 — Habits & offers (5 lessons + checkpoint C8)

**L36. Aorist (positive): habits, general truths, offers**
- The rule card starts from the A1 set phrases: *Teşekkür eder·im*, *Rica eder·im*, *Görüş·ür·üz*. "You've said these 100 times: here's the ending."
- Forms:
  - stem ends in a **vowel** → **-r**: *oku·r, bekle·r, başla·r*;
  - **one-syllable** consonant stem → **-Ar**: *yap·ar, iç·er, git → gid·er, et → ed·er*;
  - **two+ syllables** → **-Ir**: *çalış·ır, otur·ur, konuş·ur*;
  - **13 one-syllable exceptions take -Ir**: *al, bil, bul, dur, gel, gör, kal, ol, öl, san, var, ver, vur* → *alır, bilir, gelir, görür…* (a word-card flag, see §3). Gloss **var-** as *varmak* "to arrive" (≠ the particle *var*) and **san-** as *sanmak* "to think, suppose", or learners will be confused.
  - one-syllable vowel stems: *de → der*, *ye → yer* (*Ne der?* · *Kediler balık yer.*).
- Person endings as in L5 (*gel·ir·im, gel·ir·sin, gel·ir, gel·ir·iz…*).
- Meaning: habits (*Her sabah kahve içerim.*), general truths (*Kediler süt sever.*), offers and promises (*Ben yaparım.*). Contrast with **-Iyor** (now / around now).
- Pitfall: *gelir* "comes", not ~~geler~~; *yapar* not ~~yapır~~. The exceptions get their own review cards.
- **olur / olmaz** card: *Olur!* "OK!", *Olmaz.* "No way / not possible." (*olmak* in full: L39.)
- 💬 **"Say it like a Turk"** card (recognition only, see §1.1): *naber?* (ne haber), *napıyosun?* (ne yapıyorsun), *noldu?* (ne oldu), *bi* (bir: *bi dakika*, *bi şey*).

**L37. Aorist: negative and questions**
- Negative **-mAz**, but **1st person -mAm / -mAyIz**: *gelmem, gelmezsin, gelmez, gelmeyiz, gelmezsiniz, gelmezler*.
- Questions: person ending on *mI* as in the present: *Gelir misin?* *Çay içer misiniz?* Negative question: *Gelmez misin?*
- Pitfall: the negative **question** keeps **-mAz** even in the 1st person: *Gelmez miyim? Gelmez miyiz?* (not ~~gelmem mi~~).
- Tag question **değil mi?** "isn't it? / right?": *Güzel, değil mi?* (high frequency, no new grammar).
- **Polite requests and offers:** *Bir çay alır mısınız?* "Would you like a tea?" · *Kapıyı açar mısın?* "Could you open the door?" (T1b's *Türkçe konuşur musunuz?* explained).

**L38. Can / can't: -(y)Abil, -(y)AmA**
- Ability = verb + **-(y)Abil** + aorist: *yap·abil·ir·im* "I can do", *gel·ebil·ir misin?* "can you come?".
- Inability = **-(y)AmA** + negative aorist: *yap·ama·m* "I can't do", *gel·eme·z* "he can't come".
- **-(y)AmA works in every tense**: *gelemiyorum* "I can't come (now)", *yapamadım* "I couldn't do it", *gelemeyeceğim* "I won't be able to come".
- Second meaning of **-(y)Abil + aorist**, "might": *Yağmur yağabilir.* "It might rain."
- Permission and requests: *Girebilir miyim?* "May I come in?" (T1b's *Bir çay alabilir miyim?* explained).
- Pitfall: the negative is **not** *yapabilmem*: it's **yapamam**.

**L39. Must / should: -mAlI; olmak "to be / become"**
- *git·meli·yim* "I must / should go", *gitmemelisin* "you shouldn't go", *Ne yapmalıyım?*
- Compare with L35 *lazım / gerek*: *-mAlI* is more personal (duty, advice). Both are correct for "need to".
- ⭐ **olmak: "to be" in the tenses the copula doesn't have.** *Evde olmalıyım.* "I must be at home." · *Yarın evde olacağım.* "I'll be at home tomorrow." · *Doktor olmak istiyorum.* "I want to be a doctor." · *Hasta oldum.* "I got ill." (*olmak* = become). Already needed by L51 (*Hava güzel olursa*).

**L40. Let's / let me: optative -(y)AlIm, -(y)AyIm**
- *Gidelim!* "Let's go!", *Ne yapalım?* "What shall we do?", *Bakayım.* "Let me have a look.", *Kahve içelim mi?* "Shall we have a coffee?"
- *Hadi* "come on" + optative: *Hadi gidelim!*
- **3rd-person imperative -sIn** "let him / her …": *Gelsin.* "Let him come." · *Ali beklesin.* It finally explains the A1 chunks *Afiyet olsun*, *Kolay gelsin*, *Geçmiş olsun*.
- 💬 Spoken (recognition only): the vowel before *y* is raised: *geliyim, bakıyım* for *geleyim, bakayım* (as *bekliycem* in L33).

**✓ Checkpoint C8.** Weekly habits and making plans with a friend: what you usually do, what you can't do, and what you'll do together.

### Unit 9 — Finding your way (5 lessons + checkpoint C9)

**L41. Where exactly? Spatial nouns + possessive + case**
- *X'in* **üst·ü** "top" / **alt·ı** "underneath" / **ön·ü** "front" / **arka·sı** "back" / **yan·ı** "side" / **iç·i** "inside" / **dış·ı** "outside" / **karşı·sı** "opposite" / **ara·sı** "between".
- With the L24 buffer n: *masanın üst·ü·n·de* "on the table", *evin ön·ü·n·de* "in front of the house", *bankanın karşı·sı·n·da* "opposite the bank".
- Three cases, three questions: *-DA* where? (*masanın altında*), *-(y)A* where to? (*masanın altına*), *-DAn* where from? (*masanın altından*).
- The genitive can drop for a general place: *ev önünde*. Teach the full form first.

**L42. -ki: the one in / the one of**
- Place: *masa·da·ki kitap* "the book on the table", *İstanbul'da·ki arkadaşım* "my friend in Istanbul".
- Time: *bugün·kü*, *yarın·ki*, *dün·kü*, *akşam·ki*. Note *bugünkü*, *dünkü* and *öbürkü* break the rule below (fixed forms).
- Pronoun use: *Benimki* "mine", *Seninki nerede?*
- **-ki + case takes the buffer n**: *benimki·n·i*, *masadaki·n·i*, *seninki·n·de*.
- Pitfall: *-ki* never harmonises (*masadaki*, not ~~masadakı~~), except the fixed words *bugünkü, dünkü, öbürkü*.

**L43. Postpositions: için, gibi, kadar, göre, -DAn sonra / önce**
- *Senin için* "for you", *Ali gibi* "like Ali", *akşama kadar* "until the evening", *bana göre* "according to me", *yemekten sonra* "after the meal", *dersten önce* "before the class".
- The case each one takes: singular pronouns in the genitive with *için / gibi* (*benim için, onun gibi*), but **plural pronouns stay bare** (*onlar için, bunlar gibi*); the dative with *göre* (*bana göre*); the ablative with *sonra / önce / başka*.
- **kadar has two uses**: + dative "until / as far as" (*akşama kadar, eve kadar*); + bare noun / genitive pronoun "as … as" (*Ali kadar, benim kadar*), used again in L58.

**L44. Directions: imperatives + cases**
- *Sağa dönün. Düz gidin. İkinci sokaktan sola dönün. Bankaya kadar yürüyün.*
- Recap of L14 polite imperative, L17 dative, L12 ablative (*köprüden geçin*).
- Vocabulary: *sağ, sol, düz, köşe, ışıklar, karşı, geçmek, dönmek, yürümek*.

**L45. Ordinals -(I)ncI, distributives -(ş)Ar**
- *birinci, ikinci, üçüncü, dördüncü…* (after a vowel *-ncI*: *altıncı, ikinci*), *ilk* "first".
- *Kaçıncı kat?* "Which floor?" · *İkinci kattayım.*
- *birer, ikişer* "one each, two each": *Herkes birer çay içti.*

**✓ Checkpoint C9.** Lost in a new city: ask where things are, follow directions to a hotel, and describe where things are in your room.

### Unit 10 — Telling stories (5 lessons + checkpoint C10)

**L46. Past continuous -(I)yordu: "was …-ing", "used to"**
- *Kitap okuyordum.* "I was reading a book." · *Eskiden İzmir'de oturuyordum.* "I used to live in Izmir."
- Built like L15 + L32: *gel·iyor·du·m*. Negative *gelmiyordum*, question *Geliyor muydun?*
- Story frame: *Ben kitap okuyordum, telefon çaldı.* "I was reading, the phone rang."
- 💬 Spoken (recognition only): the **r** of *-yor* drops: *geliyo, geliyodum, napıyodun*; casual 1st person *gidiyom, biliyom*.

**L47. Apparently / I heard: -mIş**
- Hearsay, inference and surprise: *Ali gelmiş.* "Apparently Ali has come." · *Hava soğukmuş.* "It seems it's cold." · *Çok güzelmiş!* "Oh, it's beautiful!"
- vs **-DI** (witnessed): *Ali geldi* "Ali came (I saw it)" vs *Ali gelmiş* "Ali has come (I see his coat / I heard)".
- With nouns: *-(y)mIş*: *hastaymış* "apparently he's ill".
- Person endings from L5 (*gelmişim, gelmişsin…*). Fairy tales: *Bir varmış, bir yokmuş…*

**L48. While: -(y)ken**
- *Evdeyken* "while (I was) at home", *Çocukken* "as a child", *Yemek yerken konuşmayın.* "Don't talk while eating." (aorist + *-ken*).
- *-ken* never harmonises.

**L49. When / as soon as: -(y)IncA**
- *Eve gelince yemek yiyeceğim.* "When I get home, I'll eat." · *Seni görünce çok sevindim.*
- Subject change: the clause has its own subject (*Ali gelince başlarız*).

**L50. After / before doing: -DIktAn sonra, -mAdAn önce**
- *Kahvaltı yaptıktan sonra işe giderim.* · *Yatmadan önce kitap okurum.*
- Recap of L43 with nouns (*yemekten sonra*).
- Pitfall: *-mAdAn önce* looks negative but isn't: *yatmadan önce* = "before going to bed".

**✓ Checkpoint C10.** Tell the story of a strange day: what you were doing, what happened, what you heard happened.

### Unit 11 — If and how (4 lessons + checkpoint C11)

**L51. If (1): -(y)sA with nouns, var / yok and the aorist**
- *Evdeysen geliyorum.* "If you're home, I'm coming." · *Zamanın varsa* "if you have time" · *Hava güzel olursa* "if the weather is nice".
- Real conditions with the aorist: *Gelirsen sevinirim.* "If you come, I'll be glad."
- Person endings (the k set, L30): *gelirsem, gelirsen, gelirse, gelirsek, gelirseniz, gelirlerse*.

**L52. If (2) and wishes: verb + -sA**
- *Keşke gelsen!* "I wish you'd come!" · *Ne yapsam?* "What should I do?" · *Gitsek mi?* "Shall we go?"
- Hypothetical: *Zengin olsam ev alırdım.* is **B1** (aorist past *-ırdı*): recognise only.

**L53. By doing / and then: -(y)ArAk, -Ip**
- *Koşarak geldi.* "He came running." · *Gülerek konuştu.*
- *Kalkıp kahvaltı yaptım.* "I got up and had breakfast." (*-Ip* takes the tense and person of the last verb).
- Pitfall: *-Ip* can't be negated. For "without doing", use *-mAdAn*: *Kahvaltı yapmadan çıktım.* "I left without having breakfast."

**L54. Verbs as objects: -mAyI, -mAktAn, -mAyA**
- *Yüzmeyi severim.* "I like swimming." · *Koşmaktan hoşlanırım.* · *Okumaya başladım.* "I started reading."
- Recap: which case each verb takes (L17, L18, L12) now applies to verbal nouns.

**✓ Checkpoint C11.** Planning a weekend with conditions: if the weather is nice…, what you like doing, how you'll get there.

### Unit 12 — People & things (5 lessons + checkpoint C12)

**L55. Relative clauses (1): -(y)An "who / which / that"**
- *gelen adam* "the man who is coming / came", *kırmızı ceket giyen kadın* "the woman wearing a red jacket", *Türkçe konuşan öğrenciler*.
- Only for the **subject** (the person doing it). Object relatives (*okuduğum kitap*) come in L60.
- **-(y)An olan**, "who has / which is": *evi olan* "who has a house", *kırmızı olan* "the red one".

**L56. Reflexive and reciprocal: kendi, birbiri**
- *kendim, kendin, kendisi…* "myself…": *Kendime bir kahve yaptım.* · *Kendi evim* "my own house".
- *birbirimizi, birbirinize…* "each other": *Birbirimizi seviyoruz.*

**L57. Never, nobody, nothing: hiç, kimse, hiçbir şey, hiçbir yerde**
- Turkish **double negative**: *Hiç gitmedim.* "I've never been." · *Kimse gelmedi.* · *Hiçbir şey yemedim.*
- *Hiç … mi?* "ever?": *Hiç Türkiye'ye gittin mi?*

**L58. Comparisons (2): kadar, gibi, daha … -DAn, en … -lArDAn biri**
- *Ali benim kadar uzun.* "Ali is as tall as me." · *Annem gibi* · *dünyanın en güzel şehirlerinden biri* "one of the most beautiful cities in the world".

**L59. Describing people: appearance and character**
- Vocabulary-led lesson: *uzun boylu, kısa saçlı, mavi gözlü* (L28 *-lI* again), *sakin, komik, çalışkan, tembel, kibar*.
- Grammar recap: *-lI* adjectives, *-(y)An* relatives, *gibi*.

**✓ Checkpoint C12.** Who's who at a party: describe people and find the right person.

### Unit 13 — Opinions & plans (5 lessons + final A2 checkpoint C13)

**L60. Relative clauses (2): -DIK + possessive**
- *okuduğum kitap* "the book (that) I read", *oturduğumuz ev* "the house we live in", *Ali'nin aldığı ceket*.
- Built on the possessive endings (L19–L20) and softening: *-DIK* → *-DIğ-* before a vowel.
- Contrast with L55: *kitabı okuyan öğrenci* (subject) vs *öğrencinin okuduğu kitap* (object).
- **Scope (decided with the Turkish review, 2026-10-22): kept in A2, scoped down.**
  - **Production:** 1st / 2nd person owners with no explicit subject: *okuduğum kitap, oturduğumuz ev, istediğin zaman*. 4-way harmony + the D rule (*geldiğim, yaptığım, gittiğim*: git + *-tiğ-*, not ~~gidtiğim~~), k → ğ before the possessive vowel.
  - **3rd person with a genitive subject** (*Ali'nin aldığı ceket, öğrencinin okuduğu kitap*): rule card, recognition and word-bank items, no free typing.
  - **Fixed-phrases card:** *istediğin zaman* "whenever you want", *bildiğim kadarıyla* "as far as I know", *dediğim gibi* "as I said".
  - **Recognition only, flagged B1:** the future relative *-(y)AcAK* + possessive (*gideceğim yer*) and *-DIK* + case (*okuduğumu, aldığından*).

**L61. Purpose and reason: -mAk için, çünkü, bu yüzden**
- *Türkçe öğrenmek için Türkiye'ye gidiyorum.* · *Yorgunum çünkü çok çalıştım.* · *Yağmur yağıyor, bu yüzden evdeyim.*

**L62. Opinions: bence, sence, sanırım, -DIğInI düşünüyorum (recognition)**
- *Bence bu film çok güzel.* · *Sence?* · *Sanırım yarın yağmur yağacak.*
- *Bence de (öyle).* / *Bence öyle değil.* "I agree / I don't think so."
- *-DIğInI düşünüyorum* is shown for recognition only (full noun clauses are B1).

**L63. Connectors: hem … hem, ya … ya, ne … ne, ya da, ayrıca, sonra**
- *Hem çay hem kahve içerim.* · *Ya bugün ya yarın.* · *Ne çay ne kahve içerim.* · *Çay ya da kahve?*
- *ne … ne* takes a **positive** verb in writing (*Ne çay ne kahve içerim*); the negative (*… içmem*) is very common in speech. Teach the positive; accept the negative in typed answers with an "in writing…" note.

**L64. Future plans and promises: review of tenses**
- *-AcAK* (decided) vs aorist (promise / willingness) vs *-Iyor* (arranged): *Yarın geliyorum / geleceğim / gelirim.*
- *-mAyI düşünüyorum* "I'm thinking of …", *-mAk istiyorum*, *-mAlIyım*.
- 💬 Spoken future (recognition only, links back to L33): *-cAm / -cAz*: *gelicem, yapıcam, gidicez, gelmicem, napcaz* (ne yapacağız).

**✓ Final A2 checkpoint C13.** A conversation about the future: your plans, your opinions, and why.

### 1.1 Spoken forms (decided with the Turkish review, 2026-10-22)

Recognition only:
- They appear in **listening** exercises and in written **dialogues**, marked 💬 *spoken*, and are **never model answers**.
- A typed answer in a spoken form is graded **"almost"**, with a note: "That's how it's said; in writing: **geleceğim**." It's never silently accepted and never plain wrong.
- No production drills.
- Where they're taught: L36 (*naber, napıyosun, noldu, bi*), L40 (*geliyim, bakıyım*), L46 (*geliyo, gidiyom*), L64 (*gelicem, yapıcam, gidicez*).
- *ya* and *yani* as fillers appear in checkpoint dialogues without a card.

| `-ki` | L42 | Never harmonises, except *bugünkü*, *dünkü* (lexicon forms) |
| `-(I)ncI`, `-(ş)Ar` | L45 | Numbers as stems |
| `-(y)ken`, `-(y)IncA`, `-DIktAn sonra`, `-mAdAn önce`, `-(y)ArAk`, `-Ip` | L48–L53 | Adverbial chains |
| `-(y)sA` (with person endings), `-sA` | L51–L52 | Conditional and wish forms |
| `-(y)An`, `-DIK` + possessive | L55, L60 | *-DIK → -DIğ-* softening before a vowel |
| Spatial nouns + possessive + case | L41 | Chains already supported (`poss_3sg` + case) |

| **Spoken variants** in answers | L36, L40, L46, L63, L64 | Content format: items list spoken / informal variants separately from accepted answers; the checker grades them "almost" with an "in writing…" note (§1.1) |

## 4. How to produce it

The approach that worked for A1:

1. **Engine first:** a session adds the A2 suffixes and the `aorist_ir` flag, with test cases for every form in §3.
2. **One writing session per unit** (U8–U13, in parallel, in separate worktrees), each with its theme packs and checkpoint, following the L10 model and this outline. Each lesson and checkpoint includes its talk task ([docs/TALK_TASKS.md](docs/TALK_TASKS.md) §5–§6); new talk sentences go in `content/sentences/talk.yaml`.
3. **A Turkish review** of each unit (sentences, grammar cards, feedback messages, talk tasks and their partner texts), as for A1.
4. **Integration** in one branch, with the duplicate-ID merge script, then a single merge into `master`.
